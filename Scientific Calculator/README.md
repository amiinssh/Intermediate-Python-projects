# Scientific Calculator (Tkinter)

## Overview

This is a **Scientific Calculator** built using Python's **Tkinter** library, designed to perform a variety of mathematical operations such as basic arithmetic, trigonometric functions, logarithmic operations, and more. It is a simple GUI-based calculator application for educational or personal use.

## Features

- **Basic Arithmetic**: Addition, subtraction, multiplication, and division.
- **Scientific Functions**: Sine, cosine, tangent, hyperbolic sine, and more.
- **Mathematical Constants**: Pi (π), Tau (τ), and Euler's number (e).
- **Logarithmic Functions**: log, log10, log2, and natural logarithm.
- **Square Root & Exponentiation**: Square roots, power functions, and exponents.
- **Modulus Operation**: Returns the remainder of a division.
- **Toggle Sign**: Allows changing the sign of the current number.
- **History Operations**: Perform cumulative operations like addition and multiplication on previous results.
- **Clear and Reset**: The ability to clear the current entry or reset the calculator.

## Requirements

- Python 3.x
- Tkinter (comes pre-installed with Python)


## Usage

- **Buttons**: The calculator's interface consists of buttons for digits (0-9), arithmetic operations, scientific functions, and mathematical constants.
- **Input Area**: The current input and results are displayed in the input field at the top of the window.
- **Operations**: Click on any arithmetic or scientific function to perform the calculation. Results will update immediately.
- **Clear**: Click "C" to clear the current input, or "CE" to reset the entire calculation.

### Example Operations:
- To calculate `sin(30°)`, click `sin`, then `3`, `0`, and `=`.
- To calculate the square root of `16`, click `√`, then `1`, `6`, and `=`.
- To calculate `5 * 8`, click `5`, `*`, `8`, and `=`.
